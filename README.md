# mac-disk-inspector · 磁盘空间体检

一个双击就能跑的 macOS 磁盘空间排查工具。扫描完自动生成一份网页报告，并在浏览器里打开。

不用装任何依赖 —— 只用 `bash` / `du` / `df` / `find` 这些系统自带命令。

## 特性

- **双击即用**：不用开终端、不用敲命令，双击 `.command` 文件就跑
- **只读扫描**：绝不自动删除任何文件，只做统计和展示
- **网页报告**：本机生成的 HTML，按「可直接清理 / 实际数据资产 / 系统与开发环境」三类着色
- **macOS 原生口径**：容量按 **1000 进制**（1 GB = 10⁹ 字节）显示，数字和你 Finder 文件夹底部看到的**完全一致**
- **稀疏文件友好**：用实际磁盘占用统计，虚拟机磁盘镜像不会虚报（Parallels 的 `.hds` 逻辑大小可能虚高上百倍）
- **离线可用**：报告是纯 HTML + CSS，不依赖任何 CDN

## 用法

```bash
# 方式一：Finder 里双击
# 右键 → 打开 → 打开（首次可能需放行）

# 方式二：终端
./mac-disk-inspector.command
```

跑完后报告生成在脚本同级的 `磁盘空间报告/index.html`，并自动打开浏览器。

> 如果 macOS 提示「无法验证开发者」，右键点文件 → **打开** → 再点 **打开** 即可。

## 报告内容

| 区块 | 说明 |
|---|---|
| 指标卡 | 总容量 / 已使用 / 可用空间 / 可直接清理合计 |
| 使用率条 | 当前磁盘占用百分比 |
| 占用排行 | 前 22 项横向条形图，按分类着色 |
| 分类明细 | 可点击按钮切换分类查看 |
| 大文件 Top N | 全盘大于 1 GB 的单文件清单 |

### 三个分类

| 分类 | 颜色 | 含义 |
|---|---|---|
| 可直接清理 | 橙 | 缓存、日志、录屏代理文件、安装包、废纸篓等，删了不影响使用 |
| 你的实际数据 / 资产 | 蓝 | 图片、影片、文稿、下载、虚拟机等真正的数据 |
| 系统与开发环境 | 灰 | 系统数据库、开发者组件、工具链、应用本体 |

## 扫描范围

脚本会去 `du` 这些位置：

- `~/Library` 下的缓存、日志、容器、应用支持目录
- `~/.cache`、`~/.lmstudio`、`~/.workbuddy` 等隐藏目录
- 桌面 / 文稿 / 下载 / 图片 / 影片 / 音乐
- `/Applications`、`/usr/local`、`/opt/homebrew`、`/Library/Developer`、`/private/var/db`
- 全盘大于 1 GB 的单个文件

扫描约需 1–3 分钟，取决于文件数量。

## 关于容量单位

macOS 从 10.6 起就统一使用 **1000 进制**：

```
1 KB = 1000 字节
1 MB = 1000 KB = 10⁶ 字节
1 GB = 1000 MB = 10⁹ 字节
```

所以本工具显示的数字会与 Finder、`diskutil`、「关于本机」一致。
（`df -h`、`du -h` 用的是 1024 进制，数字会偏小，属于正常差异。）

## 环境要求

- macOS（在 Apple Silicon / Intel 上均可）
- `bash`（系统自带）
